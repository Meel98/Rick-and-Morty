# Rick and Morty
Explora los personajes del multiverso conmigo!

En esta pagina podras ver el nombre de cada personaje con el estado y su ultima ubicacion.
Con los filtros dinamicos puedes buscar cada personaje por su nombre y tambien por su estado, utilizando solo uno de ellos o los dos inclusive. 

Los personajes y su respectiva informacion se actualiza automaticamente gracias a estar conectado a la API oficial de Rick And Morty.

Este proyecto fue desarrollado bajo la filosofía **Mobile-First** / **Responsive Web Design**, garantizando una experiencia de usuario (UX) fluida, atractiva e intuitiva sin importar el dispositivo desde el que se acceda.

La interfaz se adapta de forma dinámica a diferentes resoluciones de pantalla utilizando media queries avanzadas, unidades relativas y un sistema de grillas/flexbox flexible.
